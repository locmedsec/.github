# LocMedSec

### Your Media. Your Device. Your Privacy.

LocMedSec is an open-source, privacy-first media toolkit designed to make
everyday media processing simple, powerful, and completely local.

## What you can do

- 🎬 Convert video, audio, and images
- 📦 Compress media
- 📐 Resize and transform media
- ✂️ Trim and merge video
- 🎵 Extract audio
- 🖼️ Extract frames
- ⚡ Batch process files
- 🌐 Download supported media
- 🔧 Build custom media pipelines
- 🛠️ Access advanced media processing options

## Privacy by design

- Local-first processing
- No unnecessary cloud uploads
- No mandatory account
- No unnecessary telemetry
- Your files remain on your device
- Network access is isolated to features that require it
